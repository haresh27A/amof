Recap and Review 1 Feedback
RECAP
In the Zeroth Review, we introduced the AMOF framework, identified the research gap in heterogeneous knowledge source selection and tool–source coordination, and defined the initial objectives and technologies. 
In the First Review, we analysed 10 research papers and studied INKER as the base paper, which determines when to retrieve external knowledge using IE-KRT and what to retrieve using IE-KQF. We identified the need to extend this approach by selecting suitable sources based on relevance, reliability, freshness, and cost, while coordinating them with appropriate tools. Based on the reviewer’s feedback
FEEDBACK
Feedback 1 (Dataset Uniqueness): Transition from generic benchmark corpora to custom/in-house enterprise datasets to establish distinct novelty and domain realism.
Feedback 2 (Efficiency Optimization): Refactor the routing algorithm and gating mechanics to elevate system efficiency significantly beyond the baseline 40%.

# Slide: ppt/slides/slide5.xml
  
Problem Statement
Existing LLM systems often use static or predefined retrieval strategies.
They may retrieve external information even when it is not necessary.
They do not always consider query complexity and LLM confidence when deciding whether retrieval is required.
Selecting the appropriate tool among SQL, RAG, APIs, and web search remains challenging.
Multiple information sources may have different levels of relevance, reliability, freshness, and cost.
Retrieving irrelevant or outdated sources can lead to inaccurate and unreliable responses.

# Slide: ppt/slides/slide12.xml
     
Research Gaps Identified
• Existing LLM and RAG systems mainly focus on adaptive retrieval, RAG routing, knowledge-source routing, or tool selection as separate problems.
• When a large number of heterogeneous sources are available, evaluating many sources can increase computational cost and latency.
• Existing approaches also provide limited integration between external source selection and LLM-based tool selection.
• Therefore, there is a need for an adaptive source-routing mechanism that can dynamically rank heterogeneous sources using multiple criteria and coordinate the selected sources with LLM-selected tools
.

# Slide: ppt/slides/slide14.xml
Design of the proposed work  
1. IE-KRT retrieval trigger
K(tᵢ) = (E − mᵢ) · Sᵢ; retrieve when K(tᵢ) ≥ θ = 0.25. E is query complexity, mᵢ is parametric confidence, and Sᵢ is external dependency.
2. Two-stage source funnel
Filter incompatible or inactive sources, then search normalized FAISS embeddings. For N = 10,000 and M = 55, SRR = 1 − M/N = 99.45%.
3. Six source dimensions
Relevance Rᵢ: cosine similarity. Reliability Lᵢ = α·success rate + β·availability. Freshness Fᵢ = exp(−
λΔt
), λ = 0.005. Cost Cᵢ: normalized invocation cost. Historical success Hᵢ = (successes + α₀)/(attempts + α₀ + β₀). Conflict Kᵢ: past contradiction rate.
4. Composite score
Scoreᵢ = WᵣRᵢ + WₗLᵢ + 
W_f
 Fᵢ + WₕHᵢ − W꜀Cᵢ − WₖKᵢ; weights are positive and sum to 1.
5. Evidence fusion
Deduplicate entities and flag numeric disagreements. Fused score = 0.4 × retrieval relevance + 0.6 × source score.
